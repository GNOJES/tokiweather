# 토끼날씨 v0.9.0

Android 15 이상 기기용 업데이트입니다. 기존 v0.8.0 설치본과 같은 인증서로 서명한 APK를 제공합니다.

## 변경 사항

- 미세먼지·초미세먼지 출처를 에어코리아의 가까운 측정소 실측값으로 변경했습니다.
- 현재 위치와 동 이름 선택을 개선하고, 신뢰할 만한 동 정보가 없으면 구·시 이름을 표시합니다.
- 날씨 탭을 현재 날씨 → 예보 요약 → 실시간 대기질 순으로 정리하고 Galaxy S23에서 한 화면에 보이도록 여백을 조정했습니다.
- 하단 3개 탭에 승인된 3D 아이콘과 몸 전체가 보이는 토끼를 적용했습니다.
- 설정 화면 맨 아래에 앱 버전을 표시합니다.
- 위젯 갱신 예약 복구, 수동 갱신의 성공·실패 안내, 오류 응답과 결측 기온 처리를 개선했습니다.

## 설치 및 검증

- `tokiweather-v0.9.0.apk`를 다운로드해 설치합니다. 기존 v0.8.0에서 덮어쓰기가 가능합니다.
- 단위 테스트 30개와 디버그·릴리즈 빌드를 통과했고, Galaxy S23에서 앱 설치 및 설정 화면의 `버전 0.9.0` 표시를 확인했습니다.
